# 다음 단계의 첫 질문 개선 평가

## 변경

- 이전 대화에 맞춰 다음 단계의 질문 하나를 고르고 `nextStageQuestion`으로 단계 이동과 함께 저장한다. 별도로 고르지 못하면 여러 주제를 나열하지 않는 기본 질문을 사용한다.
- 질문은 진행 DB와 개인 기록에 남으며, 일시 중단과 재개 후에도 동일하다. 이미 저장된 이전 버전의 질문은 답변과의 연결을 보존하기 위해 자동 변경하지 않는다.
- 기존 단계 완료 기준은 그대로이며 나머지 필수 조건은 단계 안에서 차례로 살펴본다. AI가 고른 주제가 실제로 가장 중요한지는 프로그램이 보장하지 않는다.

## 검증 결과

- 0.1.8 후보에서 자동 테스트 86개와 스킬 형식 검증을 통과했다.
- 질문 지정, 기본 질문, 개별 단계 이동, 질문 저장과 재개, 기존 대기 질문 보존, 잘못된 입력의 변경 취소를 자동 테스트했다.
- 후보의 훅 구성과 훅 구현은 0.1.7과 동일하다. CLI 버전과 단계 진행 엔진은 변경되었다.
- 설치된 새 버전의 훅을 통한 실제 Codex 대화 시험은 아직 하지 않았다. 0.1.7 훅의 승인을 다른 버전에 확대하지 않았다.
